# NarwhalSlicer security reporting

NarwhalSlicer is an independently maintained OrcaSlicer fork. Upstream OrcaSlicer’s maintainers and response-time commitments do not cover this fork.

For a suspected vulnerability, use **Security → Report a vulnerability** in this repository if private vulnerability reporting is enabled. If that option is unavailable, contact the [repository owner](https://github.com/penny-dealer-fr) to arrange a private reporting channel before sharing exploit details. Do not post credentials, private project files, or exploitable details in a public issue.

Include the NarwhalSlicer version and commit, operating system, affected feature, potential impact, and minimal reproduction steps. No fixed response time is promised.

If an issue is also present in upstream OrcaSlicer, follow [upstream’s security policy](https://github.com/OrcaSlicer/OrcaSlicer/security/policy). Report issues specific to OrcaCloud, Bambu Lab services, or third-party plugins to their respective maintainers.
